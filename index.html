tish — a tiny interactive shell

A small Unix-style command interpreter, written from scratch in C.

DESCRIPTION

tish reads one line at a time from the terminal, splits it into words, and checks the first word against a small table of built-in commands. If it matches, tish runs that command directly in the shell's own process. If it doesn't, tish forks a child process and hands the line to execvp, the same way any other Unix shell falls back to programs on the system.

It keeps a little state as it runs: how long it's been alive, how many non-empty lines it has read, and the last line it executed — enough to make a few of its built-ins genuinely useful rather than decorative.

SYNOPSIS

$ make
$ ./tish              # start the interactive shell
$ ./tish -h           # print usage
$ ./tish -l           # list built-in commands
$ ./tish -i <command> # run one built-in, then exit

BUILT-IN COMMANDS

help
Lists every built-in command with a one-line description.
exit
Terminates the shell.
tishtime
Prints how many seconds the shell has been running.
lines
Prints how many non-empty lines have been entered so far.
lastcom
Re-parses and re-runs the previous line, if it was a built-in.
pagesize
Prints the system's memory page size, via sysconf.
maxprocesses
Prints the maximum number of child processes allowed.
cwdplanned
Will report the working directory of a given process.
sizeplanned
Will report a process's size in pages.
